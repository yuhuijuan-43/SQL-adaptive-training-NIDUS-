条件筛选第 2 题

筛选工资大于 5000 的员工

查询工资大于 5000 的员工姓名和工资，应使用哪条语句？

建表数据
employee
idnamesalary
1Alice5000
2Bob6000
3Carol4500
建表 SQL
展开 SQL
CREATE TABLE employee (id INT, name VARCHAR(32), salary INT);
INSERT INTO employee VALUES (1,'Alice',5000),(2,'Bob',6000),(3,'Carol',4500);
预期输出
结果
namesalary
Bob6000
ASELECT name, salary FROM employee WHERE salary > 5000
BSELECT name, salary FROM employee WHERE salary >= 5000
CSELECT name, salary FROM employee HAVING salary > 5000
DSELECT name, salary FROM employee WHERE salary > 5000 GROUP BY name

employee

展开 SQL
