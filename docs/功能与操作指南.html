1. 平台简介

SQL 自适应训练平台是一个基于知识图谱点亮的 SQL 刷题平台：系统按「分类 → 知识点」逐级出题，连续答对即可点亮知识点，29 个知识点 + 7 大分类 + 根节点逐级点亮整棵知识图谱，让学习成长看得见。

项目内容
产品形态Web 应用（浏览器访问，零安装客户端）
题库规模515 道练习题（58 道选择题 + 457 道填空题）+ 50 道真题，全部含标准答案与预期输出
知识图谱37 个节点：1 根节点 + 7 大分类 + 29 个知识点（如 SELECT、内连接、窗口函数…）
核心玩法自适应进阶（图谱点亮）、自主练习、真题测试、错题集复习
多语言简体中文 · 繁體中文 · English · 日本語 · हिन्दी · Português（6 语言）
目标用户零基础转行小白、计算机专业大学生、SQL 面试准备者

2. 学员功能与操作指南

2.1 访问 · 登录 · 注册

操作步骤：
  1. 浏览器打开平台地址（本地：http://localhost:5000），进入门户首页。
  2. 点击「进入平台」进入登录/注册页（或直接访问 /login）。
  3. 新用户点击「注册」选项卡，填写用户名 + 密码。密码需 8-16 位，含大小写字母与数字（特殊字符可选）。
  4. 不想想密码？点「随机安全密码」一键生成 16 位强密码；点「随机用户名」自动生成。
  5. 注册成功自动登录并进入做题主页。
提示：注册页提供实时密码强度条（红→绿四色）与规则逐条点亮；用户名实时检查是否被占用；注册按钮在全部条件满足前不可点击。忘记密码时联系团队管理员协助重置（无需重新注册）。

2.2 门户首页与多语言

  • 门户首页（/）：浅色玻璃拟态风格，展示平台三大特性——知识图谱驱动 · 自适应推荐引擎 · 深度模式举一反三；右侧「进入平台 / 了解我们」双入口。
  • 语言切换：门户首页右上角「语言」下拉菜单，6 种语言一键切换，偏好自动记忆；其他页面自动跟随。
  • 了解我们（/about）：平台更新动态（分页展示，点击条目查看详情：概述 / 实现要点 / 开发思路 / 数据速览）+ 项目初心介绍。

2.3 自适应进阶（核心 · 图谱点亮）

这是平台的核心玩法：系统按知识图谱逐级出题，你答对的每一个知识点都会在图谱上点亮一盏灯。

出题流程（系统自动）

双循环出题：分类（枝节点）不放回 → 知识点（叶节点）不放回 → 每个知识点连续出 5 题（3 道选择题 + 2 道填空题，选择先行）。题目不足时同知识点题目循环复用。

点亮规则（叶节点——知识点，任一满足即点亮）

规则条件说明
规则 1连续答对 3 题（相邻两题间隔 ≤ 2 分钟）立即点亮并跳过该知识点剩余题目，进入下一个知识点
规则 2该知识点本轮 5 题全部答对（不计间隔）5 题出满全对即点亮
规则 3累计答对 10 道该知识点题目（自适应 + 自主练习 + 真题测试都算）每答对 2 道点亮 20%，知识点内显示 x/10 进度

点亮规则（枝 / 根节点）

  • 分类（枝节点）：圆圈内显示 x/y（已点亮知识点数 / 知识点总数），全部点亮后该分类点亮。
  • 根节点：显示 x/7（已点亮分类数 / 7），全部点亮后整棵图谱点亮。

一轮循环

操作步骤：
  1. 做题主页点击「自适应进阶」→ 查看知识图谱点亮状态 → 点「开始适应」。
  2. 逐题作答：选择题点选选项即判分；填空题在 SQL 编辑器输入后提交（实时语法高亮、括号/引号错误检测）。
  3. 答对 3 连对 / 全对 / 累计达标 → 节点点亮，页面提示「已点亮「xxx」」。
  4. 一轮 = 刷完所有未点亮知识点（至多 145 题）→ 显示完成面板 → 返回图谱界面。
  5. 点亮状态永久保留，再次「开始适应」进入新一轮（已点亮知识点自动跳过）。
提示：图谱中知识点节点上方的 x/10 是本知识点的累计答对进度；当前正在刷的知识点有红色发光标记；答题时可用右上角 👁 图标切换「色觉辅助模式」（蓝-橙-灰-紫高辨识度配色）。

2.4 自主练习

  • 做题主页点击「自主练习」，浏览全部 515 道练习题（逐题浏览）。
  • 分类筛选：按官方 7 大分类 × 29 个子标签级联筛选（如「表连接 → 内连接」），也可按难度（简单 / 中等 / 困难）筛选。
  • 选择题即时判分；填空题提交后在内存数据库真实执行比对结果集（等价写法如列顺序不同、COUNT(*) 与 COUNT(非空列) 均正确判对），答错给出「表不存在」「语法错误」等具体提示。
  • 题目卡展示：表结构面板（可折叠）、测试数据可视化表格、预期输出表格。

2.5 真题测试

  • 做题主页点击「真题测试」，进入独立真题池（50 道），模拟真实笔试场景。
  • 真题答题同样计入知识点累计答对（点亮规则 3 的进度来源之一）。

2.6 错题集（翻页复习）

  • 做题主页点击「错题集」，集中展示你在自适应进阶、自主练习、真题测试中答错的全部题目。
  • 翻页模式：每页 5 个错题，底部「上一页 / 下一页 + 第 x / y 页」翻页（首末页按钮自动禁用）。
  • 点击错题卡片查看详情：题目原文 + 表结构 + 你的答案（红）vs 正确答案（绿）+ 解析；点「返回错题列表」回到原页码。
  • 顶部「近期综合数据」（可折叠）：总答题数 / 正确数 / 错误数 / 正确率。

2.7 知识图谱可视化

  • 独立全屏图谱页（/knowledge-map），ECharts 力导向图展示 37 节点三层结构。
  • 登录状态下自动进入点亮模式：已点亮节点彩色发光、未点亮灰色、部分点亮淡彩 + 红描边；顶部统计「点亮 x / 36」。
  • 点击大分类节点展开 / 收起子知识点；「展开全部 / 重置视图」按钮调整视图。

2.8 了解我们

  • 更新动态按时间倒序分页展示（每页 4 条），点击条目弹详情：概述 / 实现要点 / 开发思路 / 数据速览，全部 6 语言版本。
  • 置顶「项目初心」介绍平台缘起与设计理念。

3. 管理员功能与操作指南

3.1 管理后台登录门（双重验证）

操作步骤：
  1. 访问管理后台（导航 → 管理后台，或 /admin-gate）。
  2. 输入管理员账号 + 密码，再输入统一管理员密钥（平台级密钥，主管理员可更换）。
  3. 双重验证通过后进入管理后台，可查看统计与用户明细。

3.2 管理员账号体系（内推码注册）

  • 管理后台 → 「管理员账号」页：用内推码注册管理员账号（页面上不显示码值，防泄露）。
  • 内推码由主管理员统一管理（生成 / 查看 / 删除），注册时实时校验。
  • 管理员账号登录后进入「管理员面板」：查看统一密钥（掩码显示可复制）、「我的同事」列表（用户名 + 最后上线时间）。

3.3 用户管理（重置 / 回退 / 删除）

重置密码（忘记密码协助找回）

操作步骤：
  1. 管理后台 → 用户明细 → 目标用户行点击「重置密码」。
  2. 设置新密码并确认；重置成功后立即生效，用户无需重新注册、答题数据保留。
  3. 重置前旧密码自动入档（最多保留 3 条），支持逐次回退。

回退密码

用户在「重置密码」处选择「回退」，可逐次恢复历史密码（每账号最多回退 3 次；管理员账号仅主管理员可回退）。

删除用户

注意：删除为不可逆操作。流程：点击「删除」→ 弹窗确认（输入 confirm 确认）→ 删除成功。同步清理该用户的答题记录、掌握度、旅程、点亮状态与密码历史；管理员账号不会被删除。

3.4 主管理员专属功能

主管理员（平台初始管理员，标记 is_primary）额外拥有以下权限，普通管理员不可见/不可操作：

功能说明
删除管理员可删除其他管理员账号（不能删除自己/主管理员），需确认 + 操作者验证，同步清理其密码历史
重置 / 回退管理员密码管理员账号的密码管理仅主管理员可执行
更换统一密钥更换管理后台统一密钥（8-64 字符），更换后对全部管理员生效
内推码管理查看全部内推码（码 + 备注 + 创建时间）、新增、删除（最后一个不允许删）

3.5 数据统计

  • 管理后台顶部数据速览：用户总数 / 答题总数 / 正确数 / 正确率 / 进行中旅程数。
  • 难度分布直方图：按题目难度（简单/中等/困难）分组的答题量。
  • 用户答题排行：单用户答题记录摘要（按用户查询）。

4. 部署与分发指南

4.1 本地启动

操作步骤：
  1. 双击 start_server.bat（Windows 一键启动）。
  2. 脚本自动探测本机 Python（多策略：PATH / py 启动器 / 常见安装目录 / 注册表），找不到时引导下载安装（默认 Python 3.13，可配置文件 server_path.conf 预设路径）。
  3. 自动安装依赖（flask / flask-cors / requests / bs4 / lxml / bcrypt / Flask-Limiter）。
  4. 启动完成后浏览器访问 http://localhost:5000。
手动启动：已装 Python 3.10+ 的环境可执行 pip install -r backend/requirements.txt 后运行 python backend/run.py。

4.2 打包发给他人

一致性保证：整个项目文件夹压缩发送即可。前端资源已全部本地化（Font Awesome / CodeMirror 不再依赖外网），任何网络环境样式一致；对方残留旧版数据库时，启动会自动重建到最新题库（515 题）。
  • 推荐方式：整个项目文件夹复制/压缩（含 backend/questions.db，数据与本地一致）。
  • 不含数据库也正常：启动时自动从 questions.json 重建（题目与本地完全一致，用户答题数据从零开始）。
  • 对方电脑若之前跑过旧版：启动时自动检测题数与题库文件不一致 → 自动重建，无需手动删库。

4.3 公网访问（ngrok）

操作步骤：
  1. 本地启动服务（默认端口 5000）。
  2. 运行 ngrok http 5000（项目自带 ngrok/ 目录）获得公网地址。
  3. 把公网地址分享给同事/学员访问（首次使用需在 ngrok 官网注册 token）。

5. 常见问题

问题解答
忘记密码怎么办？联系团队管理员，验证身份后协助重置（新密码立即生效，旧密码留档可回退）。
图谱为什么点不亮？点亮需要：连续答对 3 题（间隔 ≤2 分钟）/ 该知识点 5 题全对 / 累计答对 10 道。间隔超过 2 分钟或答错都会中断「连续」。
一轮刷完还能点亮吗？可以。一轮完成后点亮状态保留，回到图谱重新开始新一轮，直至整棵图谱点亮。
填空题判定标准？答案在内存数据库真实执行，与标准答案结果集比对（列顺序、行顺序、等价写法均正确判对）；语法错误会给出具体提示。
页面图标/编辑器显示异常？资源已本地化，正常情况下无需联网。若仍异常请确认浏览器版本较新（玻璃拟态效果需 Chrome 76+）。
别人机器上题目和我不一样？旧版数据库残留会导致题库停在旧版。现版本启动时自动检测并重建，请确认对方运行的是最新代码。
